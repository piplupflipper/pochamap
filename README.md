# pochamap 🐧💙

あーしが常用してるキーバインドだよ〜⌨️✨  
キーの置き換えはぜーんぶ AutoHotkey v2 でやってるよ💅  

なんでこんな配置にしてるの？って思ったら、[思想](docs/思想.md) を読んでね〜💭🐧  

## キーバインド 🎹

### ふつうのとき 🌸

colon に enter, atmark に backspace を当てちゃってる✨️  

![通常時のキーバインド](images/base.svg?v=27850c45)

### 変換キーを押してる間 💛

変換キーを押しながら別のキーを押すと、記号が打てちゃう〜🔣✨  
変換キーだけをちょんっと（200ms 未満）押して離すと、IME がオンになるよ🇯🇵  

![変換キーを押している間のキーバインド](images/henkan.svg?v=b3fcbf22)

### 無変換キーを押してる間 💚

無変換キーを押しながら hjkl か wasd を押すと、矢印キーになるよ〜⬅️⬇️⬆️➡️  
無変換キーだけをちょんっと（200ms 未満）押して離すと、IME がオフになるよ🔤  

![無変換キーを押している間のキーバインド](images/muhenkan.svg?v=270e9ab0)

## 使い方 🛠️

### AutoHotkey 🤖

1. [AutoHotkey v2](https://www.autohotkey.com/) をインストールしてね📥
2. `ahk/main.ahk` を起動するだけ〜🚀 ほかの `.ahk` は `main.ahk` が読み込んでくれるよ
3. Windows の起動と一緒に動かしたいなら、`Win + R` で `shell:startup` を開いて、`ahk/main.ahk` のショートカットを置いとこ📌

Pause キーを押すと全部いったん止まって、もう一回押すと復活するよ⏸️▶️  

### Google 日本語入力 🔡

Google 日本語入力のプロパティを開いて、「一般」タブの「キー設定の選択」で「編集」を押してね👆  
「編集」メニューの「インポート」から `googleime/keymap.txt` を読み込めば OK 🙆‍♀️✨
