# 修飾キーを使用しないキーバインドについて

![通常時のキーバインド](../images/base.svg?v=3d9667a7)

enterキーって遠くないですか？  
ッターンするために毎回右手をシュシュっと横移動するの、ダルくないですか？  
私はダルいです  
なのでちょっと小指を伸ばした位置に移動させました  

ついでにcapsキーをenterに変更してます  
この配置だとenter位置が線対称になり非常に美しいですね  

加えて@にBSを当てることで右手をシュシュっと動かす必要が無くなります  
じゃあ潰れた@や:はどないして打つねんという話はあとでします  

半角全角トグルはBackspaceに当てています  
こうすることで、右手でマウスを使っている時にキーボードで打ちたい基本的な操作が左手だけでカバーできるので好（ハオ）です  
最初はtabとenterを誤爆しまくると思いますがすぐ慣れます  

IMEの切り替えは無変換/変換に当てています（google IMEの設定）  
macのIME切り替えと同じです  
操作が冪等になり、いま英字だっけ？日本語だっけ？みたいにトグルで発狂することも無くなります  

c-jでescを当ててますが、これはぶっちゃけちょっと悔いてます  
10年くらい前に誰かのdotfilesで見て真似したのが始まりですが、もう誰のdotfilesだったかも覚えてません  
皆さんは真似しなくても良いと思います  

# 修飾キー（変換）について

![変換キーを押している間のキーバインド](../images/henkan.svg?v=6615ea2a)

スペース右の変換キーを押下することで修飾キーになります  
このため、このキーバインド（pochamap）を利用できるキーボードは非常に限られることになります  
そもそも英字キーには変換無変換無いしね  
おすすめはリアフォ初代です  
リアフォは第3世代まで出てますが、初代が一番スペースキー狭く、親指シフターに非常におすすめです  
私は2台持ってます  
話が逸れました  

変換押下しながら各キー押すことで記号になります  
? " & ~ _ % @ ' $ ^ ` あたりは分かりやすいんじゃないでしょうか  
!はiとなんか形が似てるから、  
|もlとなんか形が似てるからです  
*もxとなんか形が似てるし、  
+とmは形似てないですが他にいい案も浮かばないので適当に当てました  
f, jで括弧になりますが、当ててるだけで自分も普通にshift+89で括弧打ってます
